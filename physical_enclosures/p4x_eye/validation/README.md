# R21 validation records

These are static release records for the final R21 file set. They are kept
outside `tools/` because they document a completed check; they are not scripts
to run during ordinary maintenance.

- `package-validation-r21.json` records the final printable-package hash and
  mesh checks.
- `pcbway-review-package-validation-r21.json` records the supplier-review
  package hash and its included files.
- `button-keeper-clearance-review.md` records the clearance review of the
  printed button keeper and its lid ledges.

The recorded package paths reflect the layout used when the checks were run.
These records reflect their check dates; the builder subsequently verified physical assembly fit.
Use the STL files and drawings in this directory as the current release.
