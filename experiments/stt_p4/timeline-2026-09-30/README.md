# Transcription timeline, 2026-09-30

Phase-by-phase timeline of one 68-second QuartzNet 15x5 transcription session
on the P4X-EYE, captured from the G2 glasses microphone: model load (about
4 s), capture, inference per segment, delivery to the lens, and the 60-second
lens watchdog that ends a session.

- `p4-transcription-timeline.html` - interactive timeline (open in a browser);
  `ql/` holds a rendered preview.
- `tl8.json`, `tl8.txt` - the measured events behind it; `tl6.txt` an earlier run.
